# PRODIGY-CS-3
## Task 03: Password Complexity Checker

A Python-based tool built to assess the strength of a password based on several security criteria. It provides real-time, actionable feedback to users on how to improve their password complexity.

---

##  Features
** Multi-Criteria Assessment:* Evaluates passwords based on:
  * Length (Minimum 8 characters)
  * Presence of uppercase letters (A-Z)
  * Presence of lowercase letters (a-z)
  * Presence of numerical digits (0-9)
  * Presence of special characters (e.g., !@#$%^&*)
* *Dynamic Feedback:* Classifies the password as Weak, Medium, Strong, or Very Strong and gives specific tips on what is missing.


## Technologies Used
* *Python 3*
* *re (Regular Expressions):* Built-in module for pattern matching and criteria verification.
